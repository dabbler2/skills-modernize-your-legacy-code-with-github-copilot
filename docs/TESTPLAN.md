# Account Management Test Plan

This plan describes behavior implemented by the current COBOL account-management program. Unless a case says otherwise, start a fresh program run with the initial balance of `1000.00`. Run each case independently when it depends on that initial balance. The balance is held in program storage and is not persisted across program restarts.
